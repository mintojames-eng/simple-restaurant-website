# 🍴 Spice Haven - Restaurant Website

## 📌 Project Description

**Spice Haven** is a simple and responsive restaurant website created using **HTML5, Tailwind CSS, custom CSS, and Font Awesome icons**.

The website provides information about the restaurant, its special features, and contact details.

---

## 🎯 Objectives

- Create an attractive restaurant website.
- Use semantic HTML5 elements.
- Create a responsive navigation bar using Flexbox.
- Design an attractive hero section.
- Use a responsive grid for feature cards.
- Add Font Awesome icons.
- Use Tailwind CSS through CDN.
- Add custom CSS within the HTML file.
- Create a responsive design for different screen sizes.

---

## 🛠️ Technologies Used

- **HTML5**
- **Tailwind CSS**
- **CSS3**
- **Font Awesome**
- **Flexbox**
- **CSS Grid**

## ✨ Features

### 1. Navigation Bar
The website contains a responsive navigation bar with links to:

- Home
- Features
- About
- Contact

Flexbox is used to arrange the navigation items.

### 2. Hero Section

The hero section includes:

- Restaurant name
- Welcome message
- Description
- Call-to-action button
- Food-related Font Awesome icon

### 3. Feature Cards

The website contains four feature cards:

- 🌿 Fresh Ingredients
- 👨‍🍳 Expert Chefs
- ❤️ Made With Love
- 🚚 Fast Delivery

The cards are displayed using a responsive CSS/Tailwind grid.

### 4. About Section

The About section provides a short description of **Spice Haven** and its dining experience.

### 5. Footer

The footer contains:

- Restaurant name
- Location
- Phone number
- Social media icons
- Copyright information

---

## 🎨 Color Theme

The website uses a warm food-inspired color theme:

- Orange
- Red
- Yellow
- White
- Dark Gray

This color combination gives the website a warm and attractive restaurant appearance.

---

## 📱 Responsive Design

The website is designed to work on:

- 📱 Mobile phones
- 💻 Laptops
- 🖥️ Desktop computers
- 📟 Tablets

Tailwind CSS responsive classes such as `sm`, `md`, and `lg` are used to adjust the layout according to screen size.

---

## 🧱 HTML5 Semantic Elements Used

The project uses semantic HTML5 elements including:

```text
<header>
<nav>
<main>
<section>
<article>
<footer>
```

These elements make the structure of the webpage more meaningful and accessible.

---

## 🎨 CSS

Custom CSS is included directly inside the `index.html` file using the `<style>` element.

Tailwind CSS is also included using its CDN:

```html
<script src="https://cdn.tailwindcss.com"></script>
```

## 🚀 How to Run the Project

1. Download or clone the project.
2. Open the project folder.
3. Double-click `index.html`.
4. The website will open in your web browser.

### Using VS Code

Open the project folder in VS Code and open:

```text
index.html
```

Then use **Live Server** to view the website.
